# PPP 验后残差降权与天线配置

新增功能适用于 PPP，默认不开启，旧配置继续使用原有验前/验后粗差剔除。

## 配置

~~~ini
filopt.satantp = D:/WORK-FRR/RTKLIB-B2b-master2/example/rtppp/conf/igs20.atx
prcopt.elmin = 7
prcopt.robust = 1
prcopt.robust_k = 2.5
prcopt.rejionno = 100
prcopt.rejcode = 100
~~~

prcopt.elmin 的 7 可改为 10。robust=0 为原有剔除；robust=1 为 Huber 降权加原有粗差剔除。robust_k 是按观测标准差计的起始降权门限，0 采用 2.5，允许 1..10。标准 RTKLIB 配置名为 pos2-ppprobust 和 pos2-ppprobustk。

验前相位/伪距门限沿用本算例 100 m，只作为极端粗差保护。没有因本次增加降权而任意收紧门限，避免启动时状态未收敛导致误删。验后原有约 4σ 检查仍存在，当前代码以前也会剔除最大异常卫星并重新滤波。

## 降权计算

对每个历元、每颗卫星的相位/伪距及各 IF 组合分别处理：

1. 用当前权重进行预测状态的观测更新。
2. 计算验后残差 r，使用该方程原始观测方差 R0_ii 归一化：z=|r|/sqrt(R0_ii)。
3. Huber 精度权重 w=1（z≤k），否则 w=k/z，最低为 0.01。这里 w 是精度矩阵的权重，等价观测方差乘以 1/w。
4. 同历元只降低权重，5% 的变化容差避免无意义迭代。将完整协方差矩阵变换为 R'=D R0 D，D_ii=1/sqrt(w_i)。共享首频的 IF12/IF13 非对角项同步缩放，保留相关性与正定性，不能只改对角项。
5. 权重改变后从该历元同一份预测状态与协方差重新滤波，不将同一观测重复累计为独立新观测。
6. 最多沿用 8 次迭代；最后一次冻结权重，防止接受未应用的权重更新。仍超过按当前方差计算的 4σ 门限时，使用原来的整星剔除并重算。若迭代用尽仍不能通过，则不输出不合格 PPP 解。
7. 下一历元重新从原始权重开始；周跳探测与模糊度重置仍由已有代码处理。

这是按原始观测标准差归一化的工程 Huber 方案，未声称等价于考虑杠杆值的严格标准化验后残差检验。完整创新协方差 S=H P^- H^T+R、验后残差协方差以及相关观测的联合检验可以继续扩展，但需另行处理新模糊度、高杠杆观测和检验自由度。

小残差不能证明建模完整。降权有助于抑制异常数据影响，不能替代正确的码偏差、天线和轨道钟差基准处理，也不能保证每个数据集都提高绝对精度。

## 日志与验证

使用 rtppp.exe -t 2 或更高日志级别。PPPQC 行记录历元、卫星、PHASE/CODE、组合编号 IF1/IF2（对应第一/第二个 IF 组合）、残差、原始标准差、旧/新精度权重及迭代次数。

outlier (0) rejected 是验前剔除，outlier (1..8) rejected 是验后剔除。日志计数是处理事件数，不是独立异常历元数，同一历元可触发多次权重更新。

测试包含 Huber 门限、合成粗差对位置估计的影响、协方差正定性/相关性、实际 PPP 方程的降权接入、冻结最终权重及旧模式回归。

## 接收机天线未知

保留接收机天线标定功能。型号未知时使用：

~~~ini
prcopt.anttype[0] =
prcopt.posopt[1] = 0
filopt.rcvantp =
prcopt.antdel[0][0] = 0
prcopt.antdel[0][1] = 0
prcopt.antdel[0][2] = 0
~~~

这表示省略接收机 PCO/PCV，仍可保留已知的 ENU 天线几何偏心；本算例未提供偏心，保持零。后续若提供天线与天线罩型号，可指定接收机 ANTEX 文件和对应 anttype，并启用 posopt[1]。无需为了继续解算反复索要型号。

## 卫星频率标定缺失

缺失标定不是数学上无法列方程，而是模型中未知的天线项尚未处理。可以在具备可靠厂家参数或经验证的替代模型时显式使用，并考虑模型不确定度。本次未把未知标定静默置零，也未无依据跨频率复制。

当前配置 IF 路径要求组合涉及的每个卫星频段都有对应标定。缺失 G05 只影响包含 L5 的 IF13，已有 L1/L2 的 IF12 仍可参与；缺失组合共享首频时，两组 IF 都会受影响。接收机型号未知的省略策略与卫星频段缺失策略分别处理。

## 2026 年北斗 PRN 调整

新 igs20.atx 包含 C06、C07、C14、C31 等 PRN 的新卫星记录。它们在采集日期已对应北斗三号卫星，旧文件仍指向旧卫星或缺少 C05，导致本例所需三频组合被排除。

当前 IF 模型按采集历元选中的 ANTEX 卫星代际优先确定北斗二号/三号钟差组；缺少描述时再参考 B1C/B2a 信号和旧编号兼容规则。不能继续简单按“PRN>16”分类。当前 IF 模型也不再沿用针对旧 C38/C39/C40 的固定特殊权重，统一按高度角、观测类型与可选残差控制定权；传统非配置模式保持其历史行为。

## GPS 码偏差近似的准确含义

本算例实际码观测是 GPS C1C/C2X/C5Q。当前配置 IF 路径在 measurement_code_bias() 对 GPS 返回零改正，既没有把 C1C/C2X 精确换算到参考信号码，也没有为这两种实际信号应用独立的 DCB/OSB。

GPS 精密钟差与信号码基准有关。若基准 IF 由 C1W/C2W 构成，而用户采用 C1C/C2X，则理论上需要匹配产品基准的信号间偏差改正。不能只因同属 L1/L2 频段就假设码延迟相同。

IF12 码组合 P_IF=a1*P1+a2*P2，GPS L1/L2 的系数约为 2.546、−1.546。漏改正的码偏差会以 a1*δb1+a2*δb2 进入组合。1 ns 约合 0.30 m 的原始伪距偏差，但其对最终位置的影响还取决于卫星几何、滤波状态及误差吸收，不能直接等同为 0.30 m 的定位误差。

当前逐星 IFCB 主要描述第二 IF 组合相对于第一组合的附加偏差，不等于完成 C1C−C1W、C2X−C2W 的完整标定。公共偏差可被接收机钟差部分吸收，逐星不一致的偏差仍可能影响收敛和精度。此次没有凭空生成 GPS 偏差产品；要进一步完善，需要来源、有效日期、信号码和参考基准明确的 DCB/OSB，再接入并单独验证。
